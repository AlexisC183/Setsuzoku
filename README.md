# Setsuzoku

## Proyecto de Node.js

### Cómo ejecutar (Windows)

1. En la raíz del proyecto, ejecutar `Setsuzoku.bat`
- Se accede a la app a través del navegador, introduciendo http://localhost:8000 como URL
2. Para detener, presionar Ctrl+C

### Cómo ejecutar (Linux)

1. En la raíz del proyecto, ejecutar `node backend/server.js`
- Se accede a la app a través del navegador, introduciendo http://localhost:8000 como URL
2. Para detener, presionar Ctrl+C
